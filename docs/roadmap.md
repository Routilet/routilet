# Routilet 总体路线图（启动台方向）

日期：2026-11-27。此修订对应启动台预览 PR #3；旧阶段 01 Launcher v2 迁移作为历史基线保留。组织级架构尚需维护者同步确认，不能把旧 Node/npm 方案视为新启动台的实现约束。

## 产品定义

Routilet 首先是轻量应用启动台，其次是应用管理器。首页展示独立应用；点击已安装应用即打开，未安装则安装并打开，有可用更新时才展示更新。应用独立进程、独立窗口；成功提交启动请求后启动台退出。插件和资源不占用首页。Companion 正在调整为代码管理和本地评测，OJ 接入计划作为插件；具体接口由 Companion 决定。

## 实施顺序

| 阶段 | 目标 | 交付与完成条件 |
| --- | --- | --- |
| 01 完善启动台初版 | 紧凑 Wails 窗口、固定 pnpm | 本地列表、安装/更新/启动、真实进度、取消、错误提示、关闭保护、数据目录入口；双平台 CI 及真机 |
| 03 生命周期管理 | 安装管理可靠性 | 卸载、回退、修复、快捷方式；多实例/运行版本保护、安全清理、故障恢复 |
| 05 Routilet 自更新 | 首次发行前完成 | 固定初始入口、Manager npm 包更新、启动握手与故障回退；双平台模拟包及真机 |
| 首次发行 | 启动台独立发行 | 不等待其他应用，明确应用尚未就绪；构建签名、真实升级验收及发布流程 |
| 02 真实应用接入 | 首次发行后 | Observer、Companion 新版就绪再接入，归纳最小协议 |
| 04 生态整合 | 后续计划 | 等应用完成后重新规划 |

阶段 01 已有 pnpm 及 GUI 初步 CI 证据；进度和取消的新增代码需重新验证，实际 Observer/Companion 接入不能用 esbuild 模拟结果替代。

## 当前技术决策

Go + Wails，固定随包分发 pnpm 12.22.0，npm 官方 Registry，默认链接/存储，禁用安装脚本。无需用户配置 Node/PATH。pnpm 不单独管理版本、不自更新；Routilet 自更新在首次发行前完成。数据根为 OS UserConfigDir/Routilet，旧 Preview 目录不自动迁移或删除。预览阶段每应用独立快照，保留旧版本，后续明确并发保护与清理。

暂不建设第三方应用商店、自定义源、后台服务、通用插件管理框架、公共 UI 库或复杂设置。不得擅自修改其他仓库、发布正式版本、删除旧代码。真实 CI 和实机验收分别记录。
