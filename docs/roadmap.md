# Routilet 路线图

## 已发行
v0.1.0：独立桌面启动台、固定 pnpm、进度与取消、应用生命周期、管理器自更新、正式/测试通道；GitHub Release 和 npm 已完成首次发行。双平台 CI 通过，真实应用尚未接入。

## v0.1.1
正式源码 desktop/、依赖锁定、统一测试与发行、品牌图标、历史归档、文档同步。目标：真实 v0.1.0 → v0.1.1 npm 升级和 Windows/macOS 真机验收。仅修改基础工程及必要修复，不新增产品功能。

## 后续（应用就绪后）
1. Observer 首个真实应用接入：安装、启动、断网、更新、修复、回退、卸载、运行保护、manifest 兼容。
2. Companion 接入：检验模型通用性，避免重复实现编程业务。
3. Exam Kit 资源、OJ 插件以及可选应用间协作：等待实际需求再定接口。
4. 课程完整场景验收后决定 1.0。

暂不开发第三方应用市场、自定义源、常驻后台、公共 UI 库、复杂设置、pnpm 单独更新或更多系统支持。CI 和实机验收分别记录，不把模拟测试视为真实应用测试。
