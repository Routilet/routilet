认识软件与完成安装

这两个工具是做什么的？

Accoding Companion 是一个非官方的课程编程助手。它把 Accoding 上的题目和样例下载到电脑中，让你在熟悉的编辑器里写代码，再回到 Companion 运行样例、提交评测。

Companion
负责导入、管理题目、本地评测和提交。
C Exam Kit
提供常用 C 语言函数和离线速查手册，例如读入数组、排序、字符串处理和数学计算。
C / C++ 编译器
将你的代码编译成可运行的程序，例如 GCC 或 Clang。

使用 C Exam Kit 时，查到函数就能直接调用。不需要自己复制函数实现。Companion 会在测试和提交时自动整合所需函数。第 3 模块会解释这一机制。

首次安装与启动

完整解压启动包。Windows 双击 Accoding Launcher.exe，macOS 双击 Accoding Launcher.command。以后都从这个解压后的文件夹打开启动器。

在终端用方向键移动选项，按回车确认。保持联网，选择「安装」，启动器会自动准备运行环境、Companion 和 C Exam Kit。安装就绪后选择「启动」。

导入第一场比赛

找到比赛 ID

在 Accoding 网页打开课程，选择左侧「课程比赛」。找到想导入的比赛，记下第一列的比赛 ID。下图的期末复习赛 ID 为 1359，实际使用时请换成自己的比赛 ID。

导入、登录与首次配置

  1. 回到 Companion，选「导入 → 导入比赛 / 作业」。
  2. 如果未登录，软件会自动提示登录 Accoding。输入账号和密码；Tab 切换字段，Space 勾选保持登录，Enter 确认。共用电脑建议不保持登录。
  3. 输入比赛 ID。首次还没有课程目录时，软件会提示选择课程文件夹和语言。

课程文件夹是这门课所有比赛和题目的总目录，不是一场比赛或一道题的目录。粘贴完整路径、拖入文件夹，或者输入希望新建的目录路径。选择 C 或 C++ 后，软件继续导入。

理解并使用 C Exam Kit

查到函数，就能直接使用

以一道教学用的小题为例：输入 n 个整数，将它们从小到大排列并输出（1 ≤ n ≤ 1000）。这不是前面截图中的特定题目，只用来说明函数库的使用方法。

输入
5
4 1 3 2 1
输出
1 1 2 3 4

传统板子需要查找并复制函数实现。使用 C Exam Kit 则不同：题目模板已经引入整个函数库，你只需查阅调用方式。

传统板子

查找实现 → 复制函数 → 调用

C Exam Kit

查阅用法 → 直接调用

这道题会用到读整数、读数组、排序和输出数组四种功能。下一页就来找出排序接口。

按 H 查用法，而不是找源码

在 C 课程或题目页面按 H 打开对应版本的函数速查。可以逐级浏览，也可以按 / 搜索中文用途或函数名，例如「排序」或 sort_ints。

函数接口
void sort_ints(int *a, int n);
void sort_ints_desc(int *a, int n);

使用说明
原地排序前 n 项。第一个接口升序，
第二个接口降序。

调用示例 · C 复制代码
int a[] = {3, 1, 3, 2};
sort_ints(a, 4);
sort_ints_desc(a, 4);

从这里能知道：升序调用 sort_ints(a,n)，其中 n 是元素数量。函数直接修改原数组，无需接收返回值。

Tab / Shift+Tab 切换类型，C 复制当前示例，U（目录页）查看通用使用约定。R 查看相关操作，Esc 返回，G 回首页，H 关闭并保留阅读位置。长代码可左右滚动。

写出完整的排序程序

打开题目的 main.c。保留开头自动生成的脚手架头文件引用，在其下方写程序。下面四个库函数都可以直接使用。

// 保留题目原有的头文件引用
int main(void) {
    int n = read_int();
    int a[1000];

    read_ints(a, n);           // 读 n 个整数
    sort_ints(a, n);           // 升序排序
    print_ints(a, n, " ", "\n"); // 空格分隔
    return 0;
}

无需另外添加排序函数、输入函数或输出函数的定义。可以只选用你需要的函数，也可以自己写算法、自定义函数以及使用 C 标准库。

复制示例时：几行调用代码放入现有程序；含 main 的完整程序框架用于替换原程序主体。不要产生两个 main，也不要删掉已有头文件引用。

为什么开头有一行陌生的头文件？

你可能熟悉 #include <stdio.h>。C 语言也允许通过双引号引用本地头文件：

#include "../../.accoding/presets/0.6.9/expanded.h"

这行只是路径示例，不要照抄；每道题的真实路径由 Companion 自动生成。它指向课程目录中对应版本的完整函数库。C 的预处理器会读取其中的内容，因此在编辑器中就可以使用这些函数，不需要特殊编程语法。

OJ 没有函数库，怎么编译？

本地头文件只存在你的电脑上，直接把原始 main.c 粘贴到 OJ 网页，服务器通常找不到这个文件。Companion 的核心功能就是自动解决这个问题。

使用函数库的几个重要约定

输入不要混用
同一份标准输入选择库内读入函数，或选择标准输入函数。不要混用 read_int 与 scanf、getchar、fgets 等。输出可照常用 printf。
数组容量要足够
如 read_ints(a,n) 的 n 是元素个数，a 必须有足够空间。自动容量接口接收实际数组；指针和数组形参改用对应的 *_into 接口。
遵守接口条件
例如二分查找要求数组已经排序；下标从 0 开始，区间通常左闭右开。使用前看手册说明。库的输入输出与算法都需要你按题意组合。

更完整的约定可在手册目录按 U 查阅。C++ 课程不使用这套 C99 函数库，仍然可以用 Companion 导入、测试和提交普通 C++ 程序。

完成第一道题目

保存并运行样例

在编辑器中写完、保存源文件，回到 Companion 选择「运行样例」。软件读取已经保存的文件，按需装配并调用本地编译器，将程序输出与导入的官方样例比较。

排序示例输入
5
4 1 3 2 1
期望输出
1 1 2 3 4

假如误用了降序接口，样例可能出现：

行号  样例输出   我的输出
! 1   1 1 2 3 4  4 3 2 1 1

这时应回到代码中修正 sort_ints_desc 为 sort_ints，保存后再测试。实际题目的输入和期望输出由软件提供。若找不到编译器，请参照编译环境配置指引；若编译失败，则阅读报错并修正程序。

测试详情仅将不同字符标红。Tab / Shift+Tab 切换样例对比、编译诊断与运行日志（有对应内容时显示）；[ / ] 切换样例或诊断，方向键滚动，PageUp / PageDown 翻页，Home / End 跳转首尾，N / P 跳转差异，Esc 返回。编译成功但存在警告时，题目页显示警告数量，可通过「查看测试详情」阅读；警告不阻止提交。编译诊断保留原文，已知常见警告默认显示中文解释与源码上下文，按 Enter 展开或收起原文；未知诊断直接展示原文。运行日志中的 stderr 不参与答案比较。

提交通过样例的版本

样例通过后选择「提交本次通过的版本」。确认后 Companion 提交测试时使用的那份独立源码，而不是原始含本地头文件的文件。

❯ 提交本次通过的版本

本地样例通过不等于 AC。OJ 还有隐藏测试数据。提交后查看平台评测结果；若修改了 main.c，要保存并重新运行样例，再提交新版本。

日常使用与更新

联网与离线分别能做什么？

已经导入的题目、函数速查、代码编写和本地样例测试均可离线使用（本地测试需要已有编译器）。导入新题、登录、向 OJ 提交和查询远程评测结果需要联网。

以后打开现有启动器即可继续使用。同一门课导入更多比赛不必重新选择目录；另一门课使用「设置 → 切换或新建课程」。具体考试中能否使用相关资料与工具，以课程规定为准。

更新软件，不等于更新所有旧题

启动器会检查 Companion 和 C Exam Kit 的更新。没有更新提示时，直接选「启动」。旧版用户需重新下载 Routilet 新启动器；它仍可离线启动已安装的旧软件，两个新发行包均可用时才提示迁移。迁移不会删除课程文件、资源快照或登录状态。

新版资源已下载应用到当前课程后
↓
新题、未改动的题可使用新版函数库
已编写的旧题默认保留原版本

每道 C 题通过自己的头文件引用绑定资源版本。这样即使函数的接口或行为发生变化，写过的题也不会被贸然改变。手册按题目实际使用的版本显示，所以不同题目看到的版本可能不同。

资源下载后，启动器可预览当前课程的升级范围；也可在 Companion 的「设置 → 更新课程资源」中处理。批量更新默认只修改未改动的题，无法确认是否改过的题也会保留。需要升级旧题时可自行选择，软件先试编译，旧版本可撤销。
