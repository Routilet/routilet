配置 C/C++ 编译环境

Companion 需要调用电脑上已有的编译器来运行样例和提交前检查。它不会安装编译器或修改系统环境变量。请选择适合自己的方法；无需把每一种方法都做一遍。

Windows

已有可用的 GCC/G++ 时，不必重新安装。若编译环境不完整或不熟悉配置，可使用课程单独提供的离线编译环境 ZIP，完整解压并按照包内说明执行安装脚本。安装包不包含在 Companion 内，由课程另行分发。

使用 C Observer 还需要同一工具链中具有内置 Python 支持的 GDB（本轮 Windows x64）。仅能运行 GCC 不代表可以使用观察器。

配置完成后关闭并重新打开启动器。没有提供固定下载链接，也不由软件自动下载或配置编译环境。

如何配置 Windows PATH 环境变量？

PATH 告诉 Windows 去哪些文件夹寻找命令行程序。如果已有工具链但终端找不到它，可以手动添加对应 bin 目录。

  1. 在 Windows 开始菜单搜索「编辑账户的环境变量」并打开。
  2. 在上方的「用户变量」区域找到 Path，选中并点击「编辑」。如果不存在，点击「新建」，变量名填 Path，变量值填编译器的 bin 目录。
  3. 在编辑窗口中点击「新建」，填写包含 gcc.exe、g++.exe 和（若使用观察器）gdb.exe 的文件夹的完整路径，例如 C:\工具链\mingw64\bin。
  4. 逐层点击「确定」，保存设置。
  5. 关闭并重新打开 PowerShell、Companion 以及启动器，让新设置生效。

不要删除或覆盖 Path 中已有的其他条目；添加的是文件夹，不是 gcc.exe 文件本身。如果有多个 GCC 版本，可以通过 where.exe gcc 检查实际调用的路径。

macOS

打开终端，安装 Apple 命令行开发工具，按弹窗提示完成安装：

xcode-select --install

Companion 默认使用 cc 和 c++（通常为 Apple Clang），不需要额外安装 GCC。使用 Observer 还需可用的 LLDB DAP（可通过 xcrun 查找）。

Linux

Ubuntu / Debian 用户可执行：

sudo apt update
sudo apt install build-essential gdb

其他发行版请使用相应的包管理器安装 GCC 和 G++。

验证与排查

重新打开 PowerShell（Windows），执行：

gcc --version
g++ --version
gdb --version

观察器还会在运行时检查 GDB 的实际能力；缺少 GDB 不影响普通本地评测。

macOS / Linux 用户执行：

cc --version
c++ --version

能够显示版本说明终端可以找到编译器。只学习 C 语言时，C 编译器可用即可。回到 Companion，重新运行样例以验证实际编译、链接和运行。

不想修改 PATH？

在 Companion「设置 → 设置 C / C++ 编译器」中分别填写编译器可执行文件的完整路径（例如 C:\工具链\mingw64\bin\gcc.exe），输入 auto 恢复系统默认。

如果是源码语法错误、链接错误或样例答案错误，应查看对应的报错，而不是直接重新安装 GCC。
