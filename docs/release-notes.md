# Routilet 0.1.2

本版集中整理交互，不增加应用或改变安装、自更新协议。

- 首页显示明确的应用状态、安装版本及可用更新；已安装应用可离线打开。
- 安装、更新直接执行；修复、回退和卸载使用明确的确认动作。应用管理改为可键盘操作的浮出菜单。
- 底部固定版本、检查状态、设置和数据目录；自身更新仅在需要时显示。
- 普通应用与管理器共享进度、取消及操作反馈。更新完成后明确提示退出并重新打开。
- 修复异步检查覆盖状态、安装成功但启动失败、清理失败不提示等问题。
- 发行通道规则、固定 pnpm、原始入口与 Manager 启动协议不变。

真实应用完整生命周期仍需在 Observer/Companion 就绪后验证；本版还需 Windows/macOS 实机检查窗口、键盘焦点、菜单、设置与在线自更新。
