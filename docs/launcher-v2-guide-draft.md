# Launcher v2 预览说明（审核草案）

独立版本号：launcher/VERSION。普通打包仍保留旧入口；开发预览显式执行 bash scripts/package-launchers.sh <output> --managed-v2，四个平台 ZIP 启用新版入口。暂不自动发行或替换稳定下载。最终 HTML 及截图须由用户审核，不把本草案当作正式使用说明。

## 用户流程

- 解压后双击启动器，默认稳定渠道；测试者通过设置切换预览渠道。预览配置及安装独立，使用测试课程。
- 安装或更新：先暂存软件、核对实际组件，再确认启用；取消保留旧安装。更新不修改课程资源快照。旧安装离线仍可启动。
- 编译环境：独立于启动器。PATH 可找到 GCC/GDB 或 Clang/LLDB；Windows 可使用课程单独分发的离线 ZIP，不提供固定下载链接。缺工具时显示明确提示，不自动打开浏览器、不自动安装。
- Companion 运行观察：题目菜单或样例详情 O，选择输入，浏览真实执行历史。输出对照保留原字节，按支持的样例规则另显示结果。退出返回原页面。
- 设置：切换渠道、回退、查看状态；卸载仅当前新版渠道，课程、配置、其他渠道与旧安装保留。

截图待实际预览：首次安装、更新确认、渠道、观察、错误提示、回退。预览发行之前确认 npm 实际 next 版本支持安装信息接口，避免稳定渠道无法安装旧主程序；必要时在预览中明确引导切换 next。
