# Routilet 架构

v0.1.x 已实现的启动台采用 Go + Wails v3、静态 Web 前端和固定原生 pnpm 12.22.0。初始下载包含 pnpm，不需用户安装 Node。管理器自身经 npm 更新，初始入口保持原位；不独立更新 pnpm。产品与支持平台参见组织生态决策。

## 发行与安装
GitHub Release 提供初始归档，npm 官方 Registry 提供后续独立应用及管理器。正式通道取 latest；测试通道比较 latest 与 next，选择更高的兼容 SemVer，平级优先正式版，不自动降级。每应用独立快照和 activation.json；候选安装禁用生命周期脚本，校验 manifest schema 1、平台入口及 SHA256 后原子激活。应用快照使用共享 pnpm store。用户课程数据独立于安装。

## 启动与生命周期
启动台先读本地状态，异步检查更新；已安装应用断网可打开。每应用启动请求由独立监督进程持有运行标记，成功请求后启动台退出。保留当前、上一版及带标记快照，异常退出标记保守保留；不保护绕过入口启动或自行脱离的子进程。跨进程操作锁保护安装、回退、清理等。修复重装当前版，卸载不动课程数据。快捷方式指向稳定入口。

## 自更新
管理器快照独立于应用。新包校验 native manifest、版本和 probe 协议；下一次启动由原始入口派生管理器，等待前端 Ready，失败尝试上一版或原始入口。现阶段保留全部历史 Manager 快照，不自动清理运行不明的版本。原始入口图标不会因自更新而改变。CI 使用模拟原生候选验证协议，真实 GUI 及在线升级需验收。

## 后续
先接入 Observer，再接入 Companion，基于实际需求归纳公共 manifest 和可选应用间调用接口；Exam Kit 资源与 OJ 插件不作为首页应用。未确定的协作协议不提前固化。旧 TUI、Node 管理方案保存在归档分支，不参与新构建。

## 本地应用调用
见 [应用调用协议 v1](app-calls.md)。复用激活记录、原生清单和运行标记，新增无界面参数透传与有界能力查询；不承载业务协议。Companion 使用新包 `@routilet/companion`，不安装旧 Accoding 包。

## 应用偏好与分发
应用禁用标记独立于激活记录，在操作锁下写入；禁用跳过检查并拒绝新的管理器启动、查询及安装类操作，保留运行实例及安装数据。Windows 初始 ZIP 将 pnpm 移至 runtime/，仍接受旧同级布局；macOS 使用单 APP ZIP。Manager npm 协议不变。
